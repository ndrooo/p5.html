# p5.html - the p5.js markup language

p5.html is an experiment in wrapping [p5.js](https://p5js.org) for declarative use.
Use [HTML custom elements](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_custom_elements) and CSS to set up your elements, then control them with vanilla
JavaScript, your own custom elements, or any framework that can manipulate HTML.
