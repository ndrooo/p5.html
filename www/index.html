p5.html is a wrapper around p5.js which allows you to write Processing sketches declaratively using HTML, CSS, and less Javascript than usual.

Be warned: it's currently very much an experiment! Feel free to try it out, but expect it to be mostly rough edges. I'd love feedback, suggestions, and bug reports, either through GitHub or email. I'd also love to see anything you make with it!

The easiest way to get started is in the p5.js web editor. Switch to the index.html page and insert the following <script> tag into the <head> section, after the script tag for p5.js:

{% highlight "html" %} {{ p5html.scriptTag | safe }} {% endhighlight %}
