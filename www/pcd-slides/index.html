What is p5.html?

  • Processing for HTML (and CSS, and JS)
  • Very much a prototype
  • Built with HTML Custom Elements 

                            
                                
                                    
                                
                            
                            <script>
                              let x = 0;
                              function draw() {
                                document.getElementById('square').setAttribute('x', x);
                                x += 1;
                              }
                            </script>
